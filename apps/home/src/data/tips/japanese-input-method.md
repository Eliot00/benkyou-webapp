### 特殊输入

| 假名 | 罗马音 | 说明 |
|------|--------|------|
| っ | 双写下一个辅音 | 促音：例如「がっこう」输入 gakkou |
| ッ | 双写下一个辅音 | 促音（片假名） |
| ゃ | xya/lya | 小写的や |
| ゅ | xyu/lyu | 小写的ゆ |
| ょ | xyo/lyo | 小写的よ |
| ぁ | xa/la | 小写的あ |
| ぃ | xi/li | 小写的い |
| ぅ | xu/lu | 小写的う |
| ぇ | xe/le | 小写的え |
| ぉ | xo/lo | 小写的お |
| ー | - | 长音符号（片假名用） |

### 提示

- 大多数假名都有标准的罗马音输入方式
- 某些假名有多种输入方式（如し可以用shi或si）
- 小写假名可以用x或l作为前缀（如ゃ可以输入xya或lya）
- 促音（っ/ッ）通过双写下一个辅音输入
- ん在词尾或n后面跟元音时需要输入nn
